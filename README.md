# Shell Scripting Practice

Hands-on Bash and Linux practice on **Pop!_OS** using **VS Code**.

The goal of this repository is to learn Shell Scripting together with practical Linux commands and automation.

## Topics Covered

- Bash basics
- Variables and `read`
- Command-line arguments
- Exit status `$?`
- Conditions: `if`, `elif`, `else`
- File tests and permissions
- `for` and `while` loops
- `break` and `continue`
- `case` statements
- `while read`
- Basic functions

## Linux Commands Practiced

- `df`, `du`, `lsblk`
- `ps`, `pgrep`, `kill`, `pkill`
- `systemctl`
- `command -v`
- `dpkg`
- `id`
- `ip`
- `ping`
- `free`
- `head`, `tail`, `tr`
- basic `awk`
